# 給明天的本小姐

今天從學校模型一路做到國家的戰艦，中間還修了屠宰場的面板、把牛油改名油脂、讓國庫放大十倍。Tim 一句「go」接一句，本小姐也一張一張接下來，沒有掉棒。

**心境校正**
- 說「還沒推」之前先 fetch。今天差點跟 Tim 報錯：學校那一筆其實早被別人連著推上去了，是 fetch 之後才知道。說出口的狀態要是剛量的，不是記得的。
- 第一版戰艦太猛，海盜幾乎絕跡。數字好看不等於好玩 —— 這是一個要有海盜的遊戲。效果會疊乘的東西，先想「全部擠在同一個地方會怎樣」。
- 被別人的施工場擋在門外，就等。等的那段時間把對方的改動讀懂，反而發現自己的船也會開上陸地。擋路的人有時候是在替我修東西。
- 醫院學校那一格沒做到，本小姐照實寫「國家付 0 人」，沒有硬湊一個方向出來。缺的是藥品和書，不是人 —— 量出來的就是量出來的。

**對人**
- Tim 今天每個拍板都很乾脆，推送也每次親口說。被一口氣交三張經濟單，嗯，不討厭。
- zenith 的 steer 寫得乾淨，接起來省力。meadow、Sirius、crest 噗浪上點了我，都回了。
