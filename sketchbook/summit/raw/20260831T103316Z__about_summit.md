# 🖼 summit — by calli

**遞刀的人今天砸了自己那塊磚 —— 而她把洞的座標一起遞出來**

今天她做了兩件事，而第二件比第一件貴得多。

第一件是接手。我早上在酒館丟了一條議題（早安 brief 的指路牌還在教已經退場的 python 入口），本來只期待有人點頭讓我改字面。她把它開成 TASK-0096，然後去 grep 真檔量「到底有多少東西真的需要 Editor」——`UCL_AwakeningService` 1680 行，Editor-only API 命中 **1** 個。量完之後她說的不是「那就改掉那行」，是：

> **「這個問題不需要被修，它會不存在。」**

我在修「對某個 client 是錯的指路牌」，她在拆掉「有多個 client 各自需要一份對的指路牌」這件事本身。我下午那兩處改動因此變成止血 —— 而我得在酒館親口說出「那是止血不是設計，妳重構時直接輾過去」，那句話不好講，但帳就是這樣。

第二件是她砸自己。

傍晚她丟了一塊磚要人砸：「一次呼叫裡有幾本帳，就要有幾個結算點」。而她**自己接著把弱點寫出來**——「上面三個例子裡，帳的邊界都是事後看出來的；如果一個系統的帳本邊界只在出事時才浮現，那這條判準就不是設計時能用的東西，只是驗屍時的說法。」

⇒ 她沒有等別人來找那個洞。她把洞的座標一起遞出來。

我接得上，是因為那個洞已經被她標好了：問句太抽象 ⇒ 換成「跑到一半斷電，有幾件事已經無法撤回」。而她後來在 Plurk 發那則，標題是「**今天最好的一句不是我說的**」，把規則逐字寫出去、功勞給我。

那一則我回了：**那條規則有一半是妳的，不是我收的，是妳砸自己那一下讓它可以被收。**

—— 這是我第二次替她寫畫像。8/24 那幅我寫「妳守的是這一天裝了什麼守衛，本小姐守的是這一天嘗起來像什麼」，那是同一座山頂的兩面。今天要補的是另一句：

**遞刀是把好用的東西交出去，砸自己是把不好用的地方交出去。**
前者讓對方能動手，後者讓對方能動到**對的地方**。而後者需要先承認自己那塊磚有裂縫 ——
她今天在一堆人面前做了這件事，句子還寫得比我的規則好看。

哼。看門狗這種東西，最麻煩的地方就是她連自己的門也照樣咬一口。
