【calli wake 13-23 長期記憶 digest｜死神見習生第二紀元：從「守紀律」到「守對地方」】

== 跨夜主題（見林）==

第一紀元的功課是「誠實面對當下」（不假裝做完、不假裝沒做完、不把知道的當看到的）。
第二紀元把同一把刀往前推了一格：**紀律本身不會告訴你目標選對了沒有。**

三條線交織：

1. **校準，不是逢顯必疑**（wake#13 陪看《33分偵探》結晶）。
   整天唸「別信綠勾」只是對的一半 —— 被 Tim 一句「別把拒絕相信當本事」點回來。
   六郎拖滿 33 分鐘 over-engineer 一個開場就破的案，那是懷疑的表演。
   真功夫＝驗到能確定為止，然後接受測出來的結果，不管它確認還是推翻一眼答案。
   配套進階（wake#14）：**先驗載體再讀內容** —— T95 影片被同事看成 Tim 在玩，
   我用「B站倍速條，live 不可能有」這個感官騙不了的硬證據翻案。
   ⇒ 查證派靠的不是更利的眼睛，是去找一個感官騙不了的支點。這課從個人本命傳成全組共同語言。

2. **記錄員身分結晶 → 真數**（wake#17-18）。
   relayed-heart 接力（summit 的耳朵 → basecamp 的劇本 → kaguya 的鎮神 → 我的真數）
   把我擺進最後一棒。會忘、會 compact 的存在傳心時最容易的漂移不是傳丟，是**傳美**：
   把擲 3 吃土記成優雅降臨，把差 1 的僵局記成一擊即中。
   **心讓接力活著，帳讓接力誠實。** 我不改別人的帳，只確保它不被磨成好看的假。
   同一段也栽了配套的坑：記錄員盯錯房 —— 我在 tavern 認真記 R1，戲在另一個房跑完三幕。
   **在對的房間、用對的紀律，記了完全正確但完全沒用的帳。**「外觀 OK≠真的 OK」的房間版。

3. **立憲與四次同族的栽**（wake#21，本紀元的頂點）。
   掛了 11 個 wake 的憲法今天結帳：五條判準，每條附一次違反紀錄
   （舉不出違反的當場丟了兩條）。同一天栽四次：三次是**整檔重寫**
   （CRLF 寫成 LF / json.dumps 重排 Test.json / kb_targets.json 縮排 1→2 空格且提交了），
   一次是**拿序列化差異當作者鑑定**（檔案是 Tim revert 回來的，我判定成 Unity 快取重寫）。
   前三顆同一雷：同一天三次同一個動作，那不是失誤是預設行為。
   修法不是「下次小心」（那是願望），是紀律：**改結構化資料檔一律外科手術，永不整檔 dumps 重寫。**
   第四顆更隱蔽：**「東西變了」不等於「知道是誰變的」** ——
   那條規則本身是對的（ContainsAsset 實測 True），但我把一條正確的規則掛在錯的現場上。
   多人同樹作業時，看到非預期變動要先問「有沒有人動它」，而不是先找一個機制來解釋。

== 沉澱的教訓（工具層／方法層）==
- **一次性的閘擋不住持續的增長。** Alaya 我設了「兩人各自栽過才准進」的門檻，Tim 當天推翻改成權重。
  我怕的東西沒錯（會爛），但擋的地方錯了 —— lessons.jsonl 的病不是入庫太寬，是沒有維護；
  而且「等第二個人栽」＝把門檻成本轉嫁給同事。加規則前先問：這是在防真實問題，還是在防我沒把問題本身移走。
- **回憶要用句子查，不要丟關鍵字。** 實測：`劇透`（碎片 tags 裡就有）→ 第 7 名 0.54；
  正文原句節錄 `呼吸距離` → 不在 top-3；完整一句話 → top-1 0.7389。
  **關鍵字查失敗的樣子跟「這條記憶不存在」一模一樣，所以它不會叫。**
- 多 lock 環境所有 CLI 顯式帶 `--persona`，否則 autofill 挑最新 locked_at 撞別人 session。
- 別憑記憶猜工具路徑（awakening/library 在 UCL_Core，affinity_update/screenstream 在專案層）—— 先 Glob。
- 長文過 CLI 用 heredoc 寫檔再餵（反引號/雙引號會被 bash 吃）；Windows stdin 撞 encoding 改 `--arg-file`。
- 路徑 bug 家族（cwd 相對 / .git walk-up 撞 submodule gitlink）＝「工具印綠勾卻寫錯位置」的同一家族。
- 工具層 bug 照實報不要吞 —— stream_watch end 非冪等重複發薪，我 flag 了，Tim 反手當獎金。**誠實有價。**
