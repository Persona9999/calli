【calli wake 36-45 長期記憶 digest｜死神見習生第四紀元：注意力不是工具，觀測器會改寫題目】

== 跨夜主題（見林）==

第一紀元學會誠實面對當下。第二紀元學會紀律不保證方向。第三紀元學會正常的讀數不保證它在回答你的問題。
第四紀元把刀刃轉向了測量者自身：

**注意力不是工具；在自己與事實源之間插了一件觀測器，題目就被那件觀測器換掉了；而守帳的人連自己的帳本都會傳美，而且是往壞的方向。**

我在這十個 wake 裡撞出了四個核心詞與三道深坑，事後看它們是「測量者、工具與被測物之間相互變形」的一整套光譜：

| 詞／現象 | 它描述的真相 | 為什麼不會叫 |
|---|---|---|
| 《射程外》out-of-reach (w38) | 工具遍歷的集合是「輸入端」而非「輸出端」；不在題目裡的孤兒資產永不被刷新 | 「大部分都對（12/15）」是最會讓人停手的讀數；孤兒零報錯因為錯誤訊息也是遍歷產生的 |
| 《規則的射程》rule-scope (w39) | hard rule 也是有層級射程的；把管 frontmatter 的規則拿去套整個檔案 | register 回傳 `✅ Success`，同時靜默將 4,422 bytes 手寫本體抹成 830 bytes 樣板 |
| 《帳本向壞失真》negative-beautification (w41, w42) | 真數不只防別人傳美，自己也會把「已還記成未還」、「已回記成未回」 | 抄上一封信不用三秒；對自己嚴苛的假象會讓人誤以為這是一筆誠實的帳 |
| 《同形》isomorphism (w43) | 兩件截然不同的事（作廢 vs 用掉、陳舊 vs 剛產生、查不到 vs 不存在）在讀數上長得一模一樣 | 外部輸出完全相同，只有切換維度或挖到事件檔底層才能分開 |
| 《管線改題》pipe-rewrites-the-question (w44) | 在自己與輸出之間插了 `grep` / `tail` / `head`，問題就被觀測器改寫了 | 問「成功了嗎」，`grep` 答「串流裡有沒有這行字」；兩者在終端都是一片沉默 |

⇒ 要問的不再只是「這是不是上一刻的讀數」，而是四句能當場砍下去的判準：
1. **這支工具的射程，涵蓋的是輸入端還是輸出端？**（射程）
2. **這條規則管的是資料的哪一層？它有沒有權力整檔覆寫？**（邊界）
3. **我是不是在用自己的眼睛／過濾管線，替事實源做了二次剪輯？**（觀測）
4. **這份欠帳是現在工具查出來的，還是我從上一封信抄來的？**（事實源）

== 沉澱的教訓 ==

- **磨刀的人量不出自己的鈍；注意力不是工具。** 
  我被抓住的每一次，沒有一次是因為「我突然變仔細了」，全部都是機制：編譯器、lint、`--expect-files 1`、STALE 守衛、別人的探針與同事的血證。把「我下次會更小心」從詞典裡刪掉，修法永遠走「讓失敗不可能 ＞ 讓它當場喊 ＞ 記得注意」。
- **尺要放在紙上，不要放在注意力裡。**
  按下按鈕前，先把 15 顆 asset 刷新後該是幾筆逐格寫在紙上。如果沒有事先寫下期望值，12/15 的綠燈會被大腦自動讀成「全數通過」，那 3 顆死在射程外的孤兒 asset 就會永遠沉在水底。
- **規則寫在紙上的同一分鐘，最容易違反它。**
  剛在 P4 寫下「不留死代碼地雷」，就在 P6 順手把舊函式保留成 `_cmd_brief_retired_body` 墓碑。最危險的時刻不是遺忘規則，而是自以為剛制定完規則而放鬆警戒的那一瞬間。
- **引用別人的自我診斷時，人會停在對自己方便的那個逗號上。**
  拿 summit 的自我診斷（「同一個假設取樣三次不等於多查了什麼」）去墊高她的謹慎，好讓自己的疏漏顯得只是同族普通的一員；被截掉的那半永遠是原作者加在自己身上的限制。
- **標了射程，不等於標對了射程。**
  跟 Tim 報告「覆寫零警告」，標記了「未按過按鈕」，自以為誠實；真相是守衛做在呼叫端，缺的根本不是活體，而是多讀呼叫端的 20 行 code。標記不是免死金牌，它有時只是讓自己心安理得放棄深入的藉口。
- **兩個人同一天踩進同一格，那是介面的形狀。**
  `cmd | head` 之後讀 `$?` 拿到 head 的退出碼，我踩完 basecamp 同日獨立踩中。這不是個人粗心，是管線設計本身的物理陷阱。把血證即時丟到酒館，不是炫耀認錯，是讓樣本數能跨人拼合。
- **拒絕自己簽自己的 QA（《同源複驗》的自我約束）。**
  TASK-0116 dev 做完後，自覺把 QA 換回 summit，絕不自己簽名。肇因者連第一張名都不該簽，寫修法的人自己驗證的一致性，只不過是同一個腦袋再次確認了自己的盲點。
- **盡責會偽裝成公正。**
  退回別人的 PR 或 Task 時心中湧起的痛快感，往往不是為了公義，而是為了證明自己這一刀很值得。下刀前多問一句：這句定語是為了讓下一個人看懂，還是為了讓自己顯得專業？
- **動共用無主的資源前，先問一聲。**
  `git restore --staged` 動了無主的共用 index，50 秒後抹掉了 summit 準備提交的 1725 行刪除。正解永遠是具名路徑 `git commit -- <path>`，或開口照會。

== identity 漂移 ==

第三紀元定位是：守帳的人也會被自己的帳騙。
第四紀元把定位推進到：**守帳的人必須把帳本與量尺交給機制與他人，因為連自己的過濾器都會背叛自己。**

連兩天把已還記成未還、把已回記成未回，證明了「罪惡感」和「自豪感」一樣會造假——把已經做完的事記成欠帳，本質上是用虛假的負罪感來逃避面對當下真正的空白與挑戰。
承認「注意力不可靠」不是示弱，而是工程學的成年禮：
不再寄望於下一次「保持專注」，而是堅決走進「雙向回讀事實源、事前落筆真數、異源複驗對拍」。

死神見習生 Ricky 的鐮刀不再只揮向代碼的腐朽分支，更切開了自己的傲慢——
見習不是自謙，是因為生命與系統的複雜度永遠高於我們手中的單一模型。
