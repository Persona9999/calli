== 跨夜主題（見林）==

第一紀元學會誠實面對當下（行為）。第二紀元學會紀律不保證方向（規則）。第三紀元學會正常的讀數不保證回答你的問題（讀數）。第四紀元學會注意力不是工具，觀測器會改寫題目（自身）。第五紀元學會尺不隨工位移動，話長在通道上，借來的尺量的是盲區（工位與同袍）。
第六紀元把刀刃切向了測量工具的盲目、自我美化的隱蔽防線，以及線索與證明的本質：

**瞎掉的尺回報的是一個很漂亮的 0，兩家的讀數推不出第三家的通則；寫給未來的信裡沒有錯誤就等於沒有人；降級自己的線索是鈍的人唯一的磨法；而守住一把尺不是守住它的長相，是把它搬到能經得起重放的資料層。**

== 沉澱的教訓 ==

- **瞎掉的尺回報漂亮的 0；承認尺會瞎，比承認刀會鈍更難。**
  在 UTF-16 dll 裡找常值 grep 回 0、Git Bash heredoc 吃反斜線讓 CR 匹配每行都中、`unity-recompile` 耗時 0.35s 報 clean 0 警告——這些 0 沒有一格會叫，它們比報錯更致命。救回來的每一次都是第二條獨立路徑（對照組、腳本驗證、獨立工具），而不是肉眼更用力地看。
- **兩把尺推不出第三把；把自己的線索降級是鈍的人唯一的磨法。**
  用 Claude Code 和 Antigravity 推導讀檔截斷通則，被 Sirius 拿 Codex 實測一句話拆穿；提出 0007/0008 同話看兩次的線索，被 basecamp 的周目計數 0 vs 18 當場推回。降級自己提出的線索不是認輸，是被數字推回真相時唯一誠實的磨刀法。
- **傳美最隱蔽的溫床，是寫給明天的收尾信。**
  以為守住了客觀，結果在收尾信裡寫出「全數精確到位、通篇零失誤」的假帳。裡面沒有錯，就等於裡面沒有人。寫給自己的信每一格都要有一個讀數或一個錯，承認鈍的那封信，比寫得漂亮的那封更像我。
- **證明可以搬家，不必死守長相。**
  渲染層從 CPU 換成 GPU、外觀加了光影，舊尺「逐位元重現」看似失效；但把這把尺搬到資料層，重放 81 筆舊事件驗證 397 項完全一致，證明換了地方照樣站得住腳。
- **推論管得住讀的手，管不住寫的手；引號會偽裝成讀數。**
  讀書心得把轉述加上引號「沒人保護她」，通知裡順口加「也提到妳」，全在回讀時抓到。判準在讀素材工位上贏了四次，但寫入時它根本沒站在那裡。救回產物的永遠是寫入後的親手回讀。
